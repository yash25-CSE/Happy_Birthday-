BIRTHDAY SURPRISE WEBSITE — SETUP

1. Open this folder in Visual Studio Code.
2. Install/use the VS Code extension "Live Server" if you want an easy local preview.
3. Right-click index.html and choose "Open with Live Server".
4. Replace the sample wording in the HTML files:
   - Change "Your Amazing Self!" in index.html to your friend's name.
   - Change [YOUR NAME] in page5.html to your name.
   - Edit any messages and captions to make them personal.
5. Add your own photos:
   assets/photos/memory1.jpg through memory8.jpg
   You can change the filenames in page4.html if you prefer other names.
6. Add your own MP4 videos:
   assets/videos/memory1.mp4 and memory2.mp4
7. Optional music:
   add assets/music/birthday.mp3
   Music starts only when the user presses the music toggle on the welcome page.

NOTES
- Missing photos show a decorative placeholder instead of a broken-image icon.
- Missing videos show a friendly note in the viewer. Add your own video files to enable playback.
- Tailwind CSS and Google Fonts are loaded from the internet, so those enhancements require a connection. The custom CSS provides the main design.
- Open the website through Live Server for the most reliable local testing.
- Navigation: index.html → page2.html → page3.html → page4.html → page5.html → index.html.
- On page 2, the candle must be blown out before the Continue button appears.
